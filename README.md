# Autofill Bridge

Local, browser-only tool that extracts data from a saved HTML or PDF page
(loan portfolio / collection sheet exports) and autofills a matching form on
any other website via a one-time bookmarklet.

Nothing is uploaded anywhere — all parsing happens client-side in the browser.

## Deploy

This is a single static `index.html` file. Any static host works (Vercel,
Netlify, GitHub Pages). No build step, no dependencies to install.
